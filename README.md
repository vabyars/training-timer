# Интервальный таймер

Локальное SPA для циклических тренировок. Поддерживает фиксированные и случайные интервалы, звуковые сигналы и историю запусков в браузере.

## Запуск

Нужны Node.js 20.19+ в ветке 20 или 22.12+ и npm.

```sh
npm ci
npm run dev
```

Открой адрес, который напечатает Vite.

## Проверки

```sh
npm run lint
npm run build
```

Сборка проходит проверку типов и создаёт статические файлы в `dist/`. При установке зависимостей `prepare` подключает Husky в локальном клоне. Pre-commit-хук выполняет `npm run lint` и блокирует коммит при ошибке.

План реализации, критерии приёмки и макеты собраны в `training-timer-design.zip`. Отдельно можно открыть [ТЗ](TZ.md) и [интерактивные макеты](mockups.html).

Vite использует WebAssembly-версию Rollup для совместимости с политикой запуска нативных модулей на рабочем компьютере.

При свёрнутой вкладке или заблокированном экране браузер может задерживать звуковые сигналы. При возвращении отображается актуальный интервал.
